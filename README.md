> 🧠 ML Algorithms from Scratch

This repository contains simple, well-explained implementations of Machine Learning algorithms — built and explained from scratch (step by step).
Each folder includes:

• A clean Jupyter notebook

• Comments and explanations in markdown cells

• Example dataset links

• Evaluation metrics and visualizations

----
> 🎯 Purpose

I created this repo to learn and share the core ideas behind popular ML algorithms.
By building each one manually, we understand:

• How the math works behind the scenes

• How models learn from data

• How to evaluate and improve performance

----
> 📘 Algorithms Covered

| Category                     | Algorithms                                                                   |
| ---------------------------- | ---------------------------------------------------------------------------- |
| **Regression**               | Linear Regression, Polynomial Regression, Ridge Regression, Lasso Regression |
| **Classification**           | Logistic Regression, KNN, Decision Tree, Random Forest                       |
| **Clustering**               | K-Means, Hierarchical Clustering                                             |
| **Dimensionality Reduction** | PCA (Principal Component Analysis)                                           |
| **Others**                   | Gradient Descent, Normal Equation (for Linear Regression)                    |


----
> 🚀 How to Run

Clone the repository: git clone https://github.com/yourusername/ml-algorithm-from-scratch.git

Open the desired notebook (e.g., Linear_Regression.ipynb)

Run all cells in Jupyter Notebook / VS Code
